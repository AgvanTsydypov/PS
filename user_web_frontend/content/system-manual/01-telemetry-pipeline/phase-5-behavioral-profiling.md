Origin Wallets are subjected to deep telemetry scans. The system queries their historical closed positions against the isolated market identifiers, extracting raw execution data:

* `avgPrice` (Determines Entry Probability `P(E)`)
* `totalBought` (Determines Financial Mass/Gravity)
* `realizedPnl` (Determines Absolute Yield)

This raw integer data is fed into the Classification Engine, translating static balances into dynamic Behavioral Archetypes (e.g., The Insider, The Anomaly, The Operator).
