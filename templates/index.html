🌟 PolyStars

Polymarket API Client - Flask Application

📊 Get Markets

GET /api/markets

Fetch all markets with filters: ?limit=10&closed=false&tag_id=100381

🎯 Get Market by Slug

GET /api/markets/slug/{slug}

Retrieve a specific market by its slug identifier.

📅 Get Events

GET /api/events

Fetch all events with filters: ?limit=10&closed=false&order=id

🔍 Get Event by Slug

GET /api/events/slug/{slug}

Retrieve a specific event by its slug identifier.

🏷️ Get Tags

GET /api/tags

Fetch all available category tags for filtering markets.

⚽ Get Sports

GET /api/sports

Fetch sports tags and metadata with IDs and images.
